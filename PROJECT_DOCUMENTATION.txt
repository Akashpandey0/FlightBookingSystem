Flight Booking System – Development Guide (Prompts)

## Tech Stack: 
•   Frontend: React.js with Bootstrap 
•   Backend: Spring Boot (Java), MySQL 
•   Authentication: JWT-based 
•   Payment: Razorpay Integration
•   Testing: JUnit/Mockito (Spring Boot), React Testing Library 
  
## 🔰 Objective 
To build a full-stack Flight Booking System that enables users to search flights, book tickets with multiple passengers, make secure payments, and provide admin functionality for flight management with secure authentication.
